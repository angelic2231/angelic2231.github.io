# 💊 克咳片（Kekei Pian）

**克咳片**是一种临床常见的止咳定喘类中成药，具有较强的止咳、定喘、祛痰功效，常用于咳嗽、喘急气短等呼吸道症状。

> [!danger] 核心安全红线
> 组方中含有 **罂粟壳**（含阿片类生物碱）与 **麻黄**（含麻黄碱），**具有成瘾性与心血管负荷风险，严禁超剂量、超疗程长期服用！儿童、孕妇及哺乳期妇女禁用！**

---

## 1. 处方组成与配伍特点

克咳片的组方遵循中医传统**“宣降相因、散敛结合”**的原则：

| 药味名称 | 核心活性成分 / 药效机制 | 在方中的主要作用 |
| :--- | :--- | :--- |
| **麻黄** | 麻黄碱、伪麻黄碱 | 松弛支气管平滑肌，解痉平喘，宣开肺气 |
| **罂粟壳** | 吗啡、可待因、罂粟碱等阿片生物碱 | 作用于中枢神经，强力收敛肺气、镇咳止咳 |
| **苦杏仁** | 苦杏仁苷 | 降气平喘，润肠润燥 |
| **石膏** | 含水硫酸钙 | 清泄肺热，制约麻黄温燥之性 |
| **桔梗** | 桔梗皂苷 | 宣开肺气，利咽祛痰，载药上行 |
| **莱菔子** | 莱菔子素 | 降气化痰，消食除胀 |
| **甘草** | 甘草甜素、甘草酸 | 调和诸药，润肺止咳 |

---

## 2. 药理作用

1. **中枢与外周双重止咳**：
   * 罂粟壳中的微量生物碱抑制延髓咳嗽中枢；
   * 苦杏仁苷水解产生的微量产物有助于缓解感觉神经末梢刺激。
2. **平喘与支气管扩张**：
   * 麻黄碱兴奋支气管平滑肌上的 $\beta_2$ 受体，缓解支气管痉挛，减轻胸闷气喘。
3. **稀释痰液与促排**：
   * 桔梗与甘草刺激呼吸道黏膜分泌，稀释黏稠痰液，易于咳出。

## 3. 重要用药风险与减害警示

### ⚠️ 罂粟壳的成瘾与依赖性风险
* 罂粟壳是罂粟的成熟干燥果壳，含有**吗啡、可待因**等天然阿片受体激动剂成分。
* **严禁长期连续使用**：一般建议疗程**不超过 3～5 天**。若大剂量或持续服用，极易诱发身体依赖性与耐受性，突然停药可能导致打哈欠、出汗、烦躁、失眠等戒断症状。

### ⚠️ 麻黄的心血管与中枢兴奋风险
* 麻黄中所含的麻黄碱属于**拟交感神经兴奋剂**，能显著加快心率、收缩血管并升高血压。
* **高血压、冠心病、心动过速、动脉硬化、甲状腺功能亢进及失眠患者慎用或忌服**。
* 麻黄碱属于兴奋剂管制范畴，**运动员慎用**。

### ⚠️ 苦杏仁过量风险
* 苦杏仁苷进入体内水解会产生极微量氢氰酸，正常治疗剂量下具有镇咳效果，但**超量摄入可导致组织缺氧中毒**，绝不可自行加倍服药。

---

## 4. 禁忌人群与注意事项

* **绝对禁用**：
  * **儿童禁用**；
  * **孕妇及哺乳期妇女禁用**；
  * 对本品所含任何成分过敏者禁用。
* **用药时限**：
  * 服药 **3 天内** 若咳嗽、喘急等症状未见明显缓解，甚至伴有高热、胸痛或咯大量黄脓痰，必须立即停药并前往医院就诊，排查肺炎等严重器质性病变。
* **饮食与配伍禁忌**：
  * 服药期间忌烟、酒及辛辣、生冷、油腻食物；
  * 不宜在服药期间同时服用滋补性中药。
