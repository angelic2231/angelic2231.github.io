## 🌐 开源仓库与社区协作

**Angelic Wiki** 是一个完全开源、面向社区的药物科普与科学减害知识库。本站的所有文章内容、页面结构与排版样式均公开发布在 GitHub 上。

* 🐙 **项目仓库**：[GitHub - angelic2231/angelic2231.github.io](https://github.com/angelic2231/angelic2231.github.io)
* 💡 **参与贡献**：若您在浏览过程中发现任何药理表述疏漏、数据错误或有新的学术文献考证，欢迎通过 GitHub 提交 [Issue](https://github.com/angelic2231/angelic2231.github.io/issues) 或发起的 Pull Request 共同完善知识库。

## 🛠️ 技术支持与站点驱动

本站基于 **[Quartz 5](https://quartz.jzhao.xyz/)** 构建。Quartz 是一个强大且现代化的静态站点生成工具（SSG），专为将个人数字花园（Digital Garden）与 Markdown 笔记发布为交互式网站而设计。

- **官方仓库**：[GitHub - jackyzha0/quartz](https://github.com/jackyzha0/quartz)
- **官方文档**：[https://quartz.jzhao.xyz/](https://quartz.jzhao.xyz/)
- **社区交流**：[Quartz Discord Community](https://discord.gg/cRFFHYye7t)

> *“Quartz is a set of tools that helps you publish your [digital garden](https://jzhao.xyz/posts/networked-thought) and notes as a website for free.”*  
> （Quartz 是一套帮助你免费将数字花园与笔记发布为网站的工具集。）
