# 🎨 排版与格式规范

如果你想要为本站做出贡献，请参考以下格式规范。

每个格式均采用 **「实际渲染效果」+「对应 Markdown 源码」** 的形式展示，编写文章时可直接复制修改。

## 1. 标题与层级结构

### 实际效果展示
# 一级标题（通常文章最顶部使用一次）
## 二级标题（核心功能模块）
### 三级标题（细分子项）
#### 四级标题（小条目）

### 对应代码
```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
```

## 2. 气泡提示框

Callout 是 Wiki 中最常用且视觉效果极佳的信息强化组件。

### 实际效果展示

> [!note] 知识笔记
> 这里是一般背景资料或药理常识补充。

> [!tip] 实用建议
> 这里放置安全防护技巧、服药随餐提示等实用要点。

> [!important] 核心重点
> 进站必读或关键机制说明，引起读者高度注意。

> [!warning] 风险警告
> 潜在的不良反应、配伍禁忌提示。

> [!danger] 致命危险与极端警示
> 20:11 剧烈变形

## 3. 双链与站内跳转

Quartz 5 原生支持类似 Obsidian 的双括号双链，构建完整的知识图谱网络。

### 实际效果展示
- 直接跳转页面：[[免责声明]]
- 带有自定义文本的双链：[[免责声明|请务必阅读免责声明]]
- 跳转到本页面内部锚点：[[#2. 气泡提示框（Callout）|跳转到 Callout 介绍]]

### 对应代码
```markdown
- [[免责声明]]
- [[免责声明|请务必阅读免责声明]]
- [[#2. 气泡提示框（Callout）|跳转到 Callout 介绍]]
```

## 4. 文本样式与强调

### 实际效果展示
- **粗体强调**：用于突出专业术语或核心结论。
- *斜体说明*：用于英文学名、引文或补充。
- ==荧光笔高亮==：用于极为抢眼的字句高亮标注。
- ~~删除线废弃~~：用于修正或标记已废除的管理标准。
- 行内代码：`CYP2D6` 代谢酶。

### 对应代码
```markdown
- **粗体强调**
- *斜体说明*
- ==荧光笔高亮==
- ~~删除线废弃~~
- 行内代码：`CYP2D6`
```
